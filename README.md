# 万象棋助手

王者万象棋的非官方网页辅助，手机浏览器和电脑都能用。个人研究用途，非商用。

## 功能

- **阵容榜**：官方推荐榜 / 热门榜 / 新手榜，以及虎牙收录（官方榜单里没有的阵容），可按英雄、棋手、阵营、标签筛选；阵容详情含站位、分阶段运营、装备、天赋、效果牌，一键复制阵容码（可在游戏内导入）。
- **智能推荐**：选棋手、想玩的阵营、已有英雄、英雄相关天赋（如「技能突破：亚瑟」），按匹配度推荐官方和虎牙收录的阵容，并标出还缺哪些英雄和可用的 CP 天赋。
- **钻石狂潮**：开局卡包三选一——选出系统给的 3 个卡包，按标准场 / 精英场 / 大师场的评级告诉你拿哪个；全部 55 个卡包按评级排序，可按分类、阵营筛选。每套卡包对应一套狂潮阵容：卡包固定获得的牌、天赋 / 效果牌使用顺序、初始上阵顺序、后续效果锦囊推荐，站位（含后期配置组），以及 8 个拍卖回合的首选 / 备选天赋和装备与建议最高出价。
- **图鉴**：英雄、棋手、CP 天赋组合、天赋、装备、效果牌，支持拼音首字母搜索。
- **收藏**：收藏时保存阵容快照（狂潮阵容同样支持），下架后仍可查看；再次访问时提示官方新上榜 / 下架的阵容。

## 数据

数据来自王者万象棋官网公开的卡牌与阵容数据文件（`game.gtimg.cn`），由 `scripts/sync-data.ts` 抓取并整理成 `public/data/*.json`。数据数量明显异常时同步会直接失败，不会发布坏数据。

另外从[虎牙万象棋助手](https://gametool.huya.com/hokc)的阵容库补充官方榜单里没有的阵容（`lineups-huya.json`，打开网站后在后台加载），并附上它按同类阵容汇总的实战数据（对局数、平均名次、登顶率、前三率）。钻石狂潮的阵容、开局卡包、卡包评级、上阵顺序和拍卖推荐也来自虎牙（`rush.json`，同样在后台加载；官方没有公开这部分数据）；拍卖的建议最高出价按虎牙的估算公式在页面里计算。抓取逻辑见 `scripts/huya.ts`：只解析虎牙网页脚本里的数据文本（JSON 字符串和只含数据的对象字面量），不执行其代码。

虎牙拒绝 GitHub Actions 等海外机器的连接（连接超时），所以仓库里的 `data-snapshot/` 存了一份在国内网络下抓取的虎牙原始数据作为兜底。同步时虎牙拿不到数据或格式变了，就改用这份快照，和最新的官方数据一起重新整理（官方榜单优先、实战数据照常挂到官方阵容上）；连快照也没有时才跳过，只发布官方数据。快照不会自动更新，想让线上用上虎牙的新数据，需要在本机运行 `npm run snapshot` 后提交 `data-snapshot/` 并推送。

卡牌名称、文案与图片版权归腾讯所有。

## 本地运行

需要 Node.js 22。

```bash
npm install
npm run sync   # 抓取最新官方数据到 public/data
npm run snapshot  # 同上，并更新虎牙数据快照 data-snapshot/（需能访问虎牙；拿不到时报错，不用旧快照）
npm run dev    # 开发服务器
npm run build  # 类型检查 + 打包到 dist
```

## 部署

`.github/workflows/deploy.yml` 会在以下时机同步数据、打包并发布到 GitHub Pages：

- 推送到 `main` 分支、手动触发时：总是发布；
- 定时：每 3 小时一次，北京时间周四（游戏更新日）每小时一次；数据与线上一致时跳过发布。

首次使用需在仓库 Settings → Pages 把 Source 设为 **GitHub Actions**。GitHub 会在仓库 60 天无活动后暂停定时任务，届时在 Actions 页面重新启用即可。

## 技术栈

Vue 3 + Vue Router（hash 模式）+ Vite + TypeScript + Tailwind CSS 4，无后端。
